# Expense Tracker React App

**Live Demo:** [https://grand-salamander-406a15.netlify.app](https://grand-salamander-406a15.netlify.app)

## Description

Expense Tracker is a **React app** that allows users to:

- Add expenses with **name, category, and amount**
- View a list of all expenses
- Delete expenses
- See **total expenses** and a **category-wise breakdown**

The app is fully responsive and works on both **desktop** and **mobile** devices.

## Features

- Dynamic expense addition and deletion
- Real-time summary and category breakdown
- Responsive design using CSS flexbox/grid
- Built with **React + Vite**

## Technologies Used

- React (Vite)
- JavaScript (ES6+)
- CSS3 (Flexbox/Grid)

## Deployment

- Hosted on Netlify: [Live Site](https://grand-salamander-406a15.netlify.app)

## How to Run Locally

1. Clone the repository:
  git clone https://github.com/yourusername/expense-tracker.git
2.Install dependencies:
  npm install
3.Run the development server:
  npm run dev
4.Build for production:
  npm run build
